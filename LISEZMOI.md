# anantafr : mise en ligne

1. Crée un compte GitHub nommé `anantafr` et un dépôt public nommé `anantafr.github.io`.
2. Dans le dépôt : Add file > Upload files. Envoie tous les fichiers ET le dossier `assets` (glisse le contenu du dossier extrait).
   La vidéo `assets/bande-annonce.mp4` pèse environ 15 Mo : elle passe sous la limite de 25 Mo de l'envoi web.
3. Remplace `[TON PSEUDO OU NOM]` et `[TON ADRESSE EMAIL]` dans `mentions-legales.html`.
4. Le site est en ligne sur https://anantafr.github.io/ après 1 à 3 minutes.
5. Search Console : ajoute la propriété (préfixe d'URL), valide-la avec la balise HTML, envoie `sitemap.xml`, puis demande l'indexation.

Ajouter une actu : copie une carte `<article class="carte actu">` dans `actualites.html` (et sur l'accueil), puis change la date, le titre, le texte et le lien.
